# 🇺🇸 EagleReach – Civic Intelligence Platform
Empowering citizens with real-time civic intelligence — representatives, news, weather, and emergency services based on location.

🔗 Live App: https://vikesh2608.github.io/EagleReach-v2/

## ⚙️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI (Python)
- APIs: U.S. Census, OpenWeather, News Aggregation
- Cloud: Render (Backend), GitHub Pages (Frontend)
- DevOps: CI/CD with GitHub Actions


## 🚀 Features
- ZIP code & location-based civic lookup
- U.S. representatives (federal + local)
- Local and global news aggregation
- 7-day weather forecast with icons
- Emergency services quick access
- Responsive startup-style UI
